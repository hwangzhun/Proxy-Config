# Clash Verge 脚本

自用 Clash Verge Rev 全局扩展脚本，原项目为 `clash-verge-script`。

- [global_script.js](global_script.js)：主要分流脚本，包含地区分组、应用规则和 DNS 配置。
- [default.js](default.js)：原样返回配置的空白脚本模板。
- [P2P.png](P2P.png)：主要脚本使用的图标。

将 [global_script.js 原始内容](https://raw.githubusercontent.com/hwangzhun/Proxy-Config/main/clash-verge/global_script.js) 用于客户端的脚本配置。脚本需要已有节点订阅，可在顶部调整 `enable` 和 `ruleOptions`。

脚本来源及作者信息保留在文件头部。本次合并保留脚本逻辑，仅更新本仓库图标链接。

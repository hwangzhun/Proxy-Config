# Proxy-Config

自用代理配置和脚本，集中维护 Quantumult X 与 Clash Verge 的配置。

| 客户端 | 文件与说明 | 原始文件 |
| --- | --- | --- |
| Quantumult X | [配置与使用说明](quantumult-x/README.md) | [QuantumultX.conf](https://raw.githubusercontent.com/hwangzhun/Proxy-Config/main/quantumult-x/QuantumultX.conf) |
| Clash Verge Rev | [脚本与使用说明](clash-verge/README.md) | [global_script.js](https://raw.githubusercontent.com/hwangzhun/Proxy-Config/main/clash-verge/global_script.js) |

两个客户端分别使用各自目录中的文件。节点订阅、凭据和个人 MITM 证书保存在设备上。

仓库由 [Quantumult-X-Config](https://github.com/hwangzhun/Quantumult-X-Config) 和 [clash-verge-script](https://github.com/hwangzhun/clash-verge-script) 的当前文件整合而来，原仓库保留历史记录。Quantumult X 包含香港节点组、马来西亚图标更新和旧资料清理。

后续更新集中在本仓库。已有设备可以按上表更新配置来源；原仓库地址仍指向原文件。
